## What these boards ask of you

These five add no new mechanic. They apply the usual Expert-band pressure: the board is crowded, the clock keeps running while you plan, and one careless pull can cut a pit off from the color it needs. The order the colors leave the board is usually what decides whether a run stays clean.

- **Read the board before the first pull.** Note how much of each color is available and which pit needs the largest share of it. That read is what makes a workable order visible.
- **Start the big pit early.** A large pit needs a long, uninterrupted flow. Opening it while the board still has space is easier than feeding it late through a narrow gap.
- **Choose the next color deliberately.** There is no move limit, only a timer, so a considered pull beats a rushed one that has to be corrected.
- **Replay a tangled board.** Once a color is walled off, a clean restart is usually faster than trying to rescue the position. Watch the order in the video and begin again.
