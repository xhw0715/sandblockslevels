## Reaching 600 changes nothing about the boards

Six hundred levels is a round number, but the game does not mark it. Level 600 uses the same mechanics as the five hundred before it: colored sand, matching pits, and a timer instead of a move limit. What makes the Expert band hard is the amount of sand that has to travel, not a new rule.

- **Count the demand before the first pull.** Two pits can want the same color, and only one of them is easy to reach. Decide which one gets fed first while the board is still open.
- **Open the largest pit while there is room.** A big pit needs a long run of sand. Starting it late means threading that run through gaps that keep narrowing.
- **Let a color finish before switching.** Changing color partway through leaves sand stranded on the wrong side of the board. Finish the flow you started.
- **Restart a board that locks up.** When a color can no longer reach its pit, a fresh attempt with a different first pull is faster than trying to unpick the mess.
